# HalfFour

Four-bar live half-time desk for bedroom producers and AI-music finishers.

The chorus you already like stays a loop because the grid never changes. Suno and a straight 8-bar print keep the snare on 2 and 4 forever, so the hook never gets heavy enough to feel finished. HalfFour plays that decision with a live band: eight bars straight, four bars of the same chords in half-time, four bars back so the top lands heavier than it left.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and an acoustic kit from the PreEight bank. No oscillators. Audio stays in the tab until you export a WAV or the half-time MIDI.

## What people were stuck on

[@SauceFromVeli](https://x.com/SauceFromVeli/status/2104932538015977836) yesterday: unfinished songs — the beat that was almost there, the hook that never found a verse, the song you loved and could not finish. VerseEight / FromHook already seat the verse. DoorTwo is the entrance.

[@batsybateman](https://x.com/batsybateman/status/2103845799499043326): good tunes that still feel like unfinished ideas — fine as a TikTok loop, not a record, because the structure never changes weight.

[@beatboyjw](https://x.com/beatboyjw/status/2023086327063785866): the expensive details are the small arrangement moves, including knowing when the pattern itself has to change.

HalfFour is that grid change. Not a new section.

## Play

- **A · Straight** — the unfinished chorus, looping
- **B · Weight** — straight, four bars of half-time, straight return
- **H · Half only** — the four bars you drop into the DAW

Recipes: Anchor, Two-step, String bed, Horn lean, Crash door, Walk back.

Exports: punch list, one-pass WAV, half-time MIDI.
